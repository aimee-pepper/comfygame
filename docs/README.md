# `docs/` — what's live

**This folder is the source of truth** (CLAUDE.md). Anything in `archive/` is not — it's there
because its content was folded into a living document, or because what it describes is built.

Read in this order on a new session: `design-brief-v0.md` → `decisions-log.md` →
`open-questions.md` → `BACKLOG.md` (repo root). **The newest dated entries win** where they conflict
with older brief text.

## The spine

| File | What it's for |
|---|---|
| `design-brief-v0.md` | The original brief. Oldest, and still the shape of the thing |
| `decisions-log.md` | Every decision, by session. **Appended up to session 15** |
| `decisions-session-16.md`, `-17.md` | Session drops **not yet folded into the log** — read them alongside it |
| `open-questions.md` | The long-standing questions, Q-A to Q-G |
| `questions-for-design.md` | Questions raised while building, with their answers as they arrive |
| `for-design.md` | **The referral list** — what's waiting on the designer, ordered by what it unblocks |
