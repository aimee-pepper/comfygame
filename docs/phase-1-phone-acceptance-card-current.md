## Checkpoint A — current fresh-save observation

Record the save name and three ordinary world returns if practical.

- [ ] A world contains no more than one named traveller.
- [ ] A traveller appears only when every required condition is present.
- [ ] The traveller summary and every recovered page appear in the return summary.
- [ ] Record Raw Essence collected, refined Essence before/after, bind cost and ending spendable
      Essence for each return.

**Immediate failure:** two travellers in one world; a traveller with an unmet condition; a recovered
page/person absent from the summary; or no credible next-bind runway after reasonable exploration.
