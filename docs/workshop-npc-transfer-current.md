# Workshop NPC transfer — current authority

**Status:** Direct Aimee implementation authority. The standalone Workshop is removed. Every one of its
54 live grants remains obtainable from a named existing traveller source before the Workshop route is hidden.
**Scope:** stable ownership, acquisition, migration and consumer continuity only. This packet does not add
a traveller, building, currency, research tree or Party teaching surface.
**Updated:** 4 September 2026 (field-pack rows only).

**Scope of this retained record:** The carrying packet supersedes only the field-pack transfer below. Other sections retain historical transfer context and must be read with their later individual authorities; this copy does not revive superseded Binder or recovered-teaching rules.

## Closed player rule

The Workshop is not a player-facing building, button, research shop or fallback. Nothing it currently grants
may disappear when it is removed.

Every transferred grant has one named source. The first two pack projects use the opening Storehouse without a traveller gate. A traveller may hand over a signed instruction which
the Library preserves and applies, or may own a physical improvement service at the relevant building. The
Library is the record and reading place, not the teacher. Party selects and applies known Gambits; Party never
teaches, sells or researches them. Anonymous world observation may satisfy a lesson's evidence requirement,
but it is not the source of the lesson.

Existing Workshop node IDs remain the compatibility identity of the exact entitlement. They are not reused as
visible Workshop destinations. Existing costs and effects remain authoritative for this relocation unless a
separate accepted tuning packet changes them.

## Transaction and persistence contract

1. A lesson quote binds the stable legacy entitlement ID, exact reward ID/kind, named `teacherID`, teacher
   availability, required durable evidence, campaign band and current ownership.
2. Commit inserts one durable signed lesson/entitlement receipt before presentation. Library read applies the
   exact reward and acknowledges only that record. Duplicate/already-known is idempotent and never pays twice.
3. Physical project quotes bind exact project ID, NPC source, prerequisite stage, capacity before/after, cost
   and exact stock custody. Commit consumes and applies atomically.
4. Existing completed Workshop nodes map one-to-one to the same entitlement IDs. Knowledge becomes an already
   read signed legacy lesson; capacity and slot effects remain exact; automation remains enabled. No refund or
   second acquisition occurs.
5. A fresh campaign never renders Workshop or purchases a nil-station branch. A decoded legacy Workshop route
   returns to THE COTTAGE with a truthful one-time notice that its work now belongs to the named people and
   places; it never opens `WorkshopView`.
6. Removing the route cannot alter Writing vocabulary, Gambit writability/execution, automation, Storehouse or
   Field Kit capacity, packed contents, Waiting, current inventory, current page, world or navigation state.

The current recovered-teaching save shape can remain schema-neutral if immutable catalogue definitions add
and validate `teacherID`, and existing migrated records derive their frozen legacy teacher from this exact
mapping. Capacity can preserve the existing exact tier integers while the new NPC-owned project UI targets the
next value. Allocate a new durable shape only if implementation proves these existing identities cannot encode
the one-to-one entitlements without ambiguity.

## Current runtime gap (verified 1 September 2026)

- `workshop` is still `unlockedAtStart`, THE COTTAGE renders it, `AppRoute.workshop` opens `WorkshopView`, and
  `ResearchTree()` renders all five nil-station branches. New campaigns therefore still depend on Workshop.
- The 38 recovered-teaching definitions, collection, Library read/apply and schema-11→12 legacy conversion are
  implemented, but definitions/records have no named traveller ownership. They do not satisfy this authority.
- All nine shelving and five satchel nodes remain Workshop purchases. No NPC-owned replacement actions or
  lossless cutover exist.
- No decode-only Workshop redirect exists. Tutorial and Party copy still direct players to Workshop.
- Tests still assert Workshop visibility, its five branches and live purchases. Those are regression tests for
  the obsolete model, not evidence that removal is safe.
