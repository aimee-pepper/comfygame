# Player-Facing Vocabulary — settled

**Settled vocabulary, after this session:**

| Player-facing word | What it means | Was |
|---|---|---|
| **Subject** | One of the eight things a world has — Illumination, Thermal, Hydrology, Substrate, Relief, Vitality, Atmosphere, Cycle | *target* |
| **Focus** | A thing acting on a subject. The palette section is **Focuses** | *cause* / *source* |
| **Main focus** | The one focus a subject is chiefly about — only one allowed, until chaining is learned | *primary* |
| **Modifier** | A qualifier written onto a focus | unchanged |
| **Compound** | A learned single glyph meaning several things | unchanged |

So a page reads as a sentence: **a subject, its main focus, and modifiers.** *Illumination, focused on the Sun, greatly.*

---

## Word 1 — the eight things a world has

Illumination · Thermal · Hydrology · Substrate · Relief · Vitality · Atmosphere · Cycle.

The palette gives each its own bin, so the player sees them constantly — but the *category* is never named. Strings currently say **target** (my spec word) in one place and **subject** in another.

| Candidate | For | Against |
|---|---|---|
| **Subject** | Completes the sentence the palette already implies: *subject ← causes + modifiers*. Grammatical, so it fits a game about writing. Already in one string | Slightly abstract on its own |
| **Condition** | The most natural description of what they are. Diaries already talk about a world's conditions | **Collides** — "conditions" already means the requirements in a traveller's signature |
| **Aspect** | Short | **Collides** — already the internal word for sub-values like dispersion and openness |
| **Element** | Familiar | **Collides** with elemental damage |
| **Force** | Evocative | Cycle isn't a force; neither is Substrate |

**My recommendation: Subject.** It's the only one with no collision, and it makes the writing desk read as a grammar — *Illumination* is the subject, *Sun* is a cause, *great* is a modifier. That's a sentence, which is exactly what a page is meant to be.

## Word 2 — the one main focus allowed per subject — **FOCUS** (Aimee)

Was **primary**, an adjective doing a noun's job. Now: **a subject has one main focus.**

*"Only one main focus per subject."* · *"Illumination's main focus is the Sun."*

It reads naturally, needs no explanation, and it says the right thing — a focus is what a subject is chiefly *about*, which is exactly the rule.

### The collision — RESOLVED: the stat is renamed (Aimee)

**Focus is also a character stat.** Session 17 proposed five: Might · Finesse · Fortitude · Perception · **Focus**, the last governing skill potency, cooldowns and gambit slots.

Two Focuses in one game is one too many. **Session 17 isn't built yet, so the stat is far cheaper to rename than the writing term.**

Candidates for the stat, keeping the same job (skill potency, gambit slots — mental sharpness):

| Candidate | Notes |
|---|---|
| **Wit** | Short, warm, fits a game about literacy. Pairs well with Might and Finesse |
| **Insight** | Clear, slightly formal |
| **Acuity** | Precise, a touch clinical |
| **Clarity** | Evocative, but vague about what it does |
| **Study** | Ties to the Library and rune work — though it reads as an activity, not a capacity |

**Decided: the stat is renamed, not the writing term.** Aimee, 6 Aug. **Wit** unless she says otherwise — Might · Finesse · Fortitude · Perception · Wit is a clean set with no remaining collisions anywhere in the design.

### The palette section — **Focuses** (Aimee)

*"Causes does not make sense, focuses is fine."* So the section becomes **Focuses**, and every source is a focus.

The one-per-subject rule then reads as **main focus**, which is ordinary English and needs no teaching: *"only one main focus per subject."*
