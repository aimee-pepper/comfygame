# Current Design — Midgame Diary Packets

**Status:** implementation-ready authored content plan for Nessa, Corrin, Dagg, Rook and Lys.
Nessa/Corrin/Dagg/Rook have eight pages; Lys has nine. Each condition receives one location page and
every other page grants exactly one focus, gambit component, whereabouts, site or worthwhile world.

The dedicated gambit page schema is defined in `diary-packets-early-mid-current.md` and is reused
here.

## Forward-reference and implementation order

- **Can land when all five definitions land together:** Dagg ↔ Talin/Halloway; Rook ↔ Mara/Fen;
  Lys ↔ Edren/Isolde. Their referenced existing/earlier IDs must validate first.
- **Defer until target exists:** Nessa → Auber; Corrin → Bracken/Kestrel; Lys → Perren if those later
  definitions are not part of the same catalog batch.
- A deferred page still counts in the authored packet but not in the live completion total until it
  can validate. Never replace it with an unrelated filler page merely to hit a number early.

## Validation rules

1. Four location pages reproduce the conditions in `traveller-signatures-mid-current.md` exactly.
2. Focus and gambit pages permanently grant one known component and nothing else.
3. Relationship pages are redundancy/story, never prerequisites for finding the target.
4. Site pages reveal a definition but do not force placement.
5. Completion rewards remain separate from recruitment and are not defined by this packet.
