## Shared grammar

- Design for a legible 20–24px interior inside a 44×44-point target. Start with one dominant filled
  silhouette and at most one cutout/secondary stroke.
- A glyph depicts the node's **cause or action**, not an arbitrary RPG category. Heavy Hand is a
  descending weight; Follow Through is continued motion; neither is a generic sword.
- Discipline family resemblance comes from a quiet corner motif outside the pictogram: Force wedge,
  Precision point, Swiftness wind notch; Fortitude block, Protection arch, Evasion offset; Venom
  droplet, Emanation rays, Shadow crescent. The central glyph remains individually recognizable.
- Owned/available/blocked/selected use node frame/fill. Technique uses a separate action pip;
  capstone uses a separate crown frame. Never recolor the pictogram to carry those facts.
- Avoid letters, numerals, skulls, medical crosses and color-only flame/poison distinctions. Burn,
  poison and dazzle retain flame/droplet/ray geometry in literal grayscale.
- Mirroring is meaningful only when specified. Do not mirror two unrelated nodes merely to fill
  opposite branches.

## Collision and comprehension proof

Before native promotion, AssetLab must show all 72 at actual interior size in color and literal
grayscale, plus the nine discipline motifs and all state-frame combinations. Blind-label review uses
at least these deliberately confusable groups:

- Heavy Hand / Follow Through / Breaking Blow;
- Quick Step / Quicken / Cascade / Blur;
- Brace / Bulwark / Shieldwall / Guardian;
- Footwork / Sidestep / Slippery / Fall Back;
- Tainted Edge / Envenom / Virulence / Blight;
- Sparkhand / Emanation Strike / Attunement / Emanant;
- Conceal / Ambush / Shadowed / Unseen.

Also test these **cross-discipline or same-purpose collisions**, because a player sees the combined
action/owned-node vocabulary rather than nine isolated contact sheets:

- Ward / Quench / Snuff — all use a hand beside a harm mark, but must read as choose protection /
  remove one ally condition / suppress a foe's emanation;
- Cover / Interpose / Guardian — shared damage / receive the next hit / close back-rank targeting;
- Second Wind / Rally — self-heal on defeat / heal the other conscious party members;
- Anatomy / Flense — expedition butchery knowledge / active covering-scaled wound technique;
- Low Profile / Shadowed — personal one-tile detection reduction / strongest party two-tile rule;
  and
- Emanation Strike / Conduction — chosen direct emanation attack / one non-recursive carried hit.

The target is not perfect icon-only guessing. It is rapid distinction within a visible discipline
and accurate recognition after the anchored name/detail has been seen once. Any pair that shares the
same dominant silhouette at 24px must be redrawn rather than distinguished only by color or a tiny
corner accent.
